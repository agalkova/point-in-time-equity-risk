# Research archive

This directory preserves superseded research generations so the project history remains visible.
The archived scripts retain their original code and assumptions, but they are not maintained as
commands that run from inside `archive/`.

To reproduce an archived experiment in its original repository layout, check out tag `v1.0.1`.
That tag points to commit `2941c64`, before these files moved into the archive.

The active research path is documented in the root README. Files under
`archive/research-generations/` are supporting history rather than current entry points or claims.
Later comparisons still read the frozen v0.3 configuration, but they use shared package code rather
than importing an archived script.
